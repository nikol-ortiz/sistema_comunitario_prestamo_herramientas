# Sistema Comunitario de Préstamo de Herramientas
## Integrantes:
- Nikol Ortiz
- Andés Pinzón

Este sistema cuanta con dos modulos:
- Modulo de administrador
- Modulo de residente

En el modulo administrador, se puede:
- Gestionar las herramientas
- Gestionar los usuarios
- Gestionar los préstamos
- Consultar y generar reportes
- Gestionar los permisos a manejar


En el modulo residente, se puede:
- Consultar las herramientas disponibles
- Solicitar un préstamo de herramienta
- Ver sus solicitudes y préstamos actuales


El programa fue creado con Python, utilizando la biblioteca de datos JSON y la biblioteca de logging para registrar los eventos. Además tambien fueron usadas para distintas funciones bibliotecas como os y datetime.
